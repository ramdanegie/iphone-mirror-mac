# Catatan perubahan

Semua perubahan penting di Cermin. Cermin menampilkan bagian untuk versimu sekali setelah update (Pengaturan → Tentang → Yang baru).

## [1.3.0] - 2026-11-04

### Ditambahkan
- Cek update: Cermin bisa mencari rilis baru di GitHub (Pengaturan → Tentang), menampilkan catatan rilis, dan mengunduh DMG. Cek harian bersifat opt-in, jadi Cermin tetap offline kecuali kamu menyalakannya atau menekan "Periksa sekarang".
- Yang baru: setelah update, Cermin menampilkan perubahan di versimu sekali.

## [1.2.0] - 2026-11-04

### Ditambahkan
- Seluruh app dalam bahasa Inggris dan Indonesia: menu, onboarding, pengaturan, setup dan diagnostik wireless, prompt, dan permintaan izin.
- Pengaturan → Umum → Bahasa: ikuti sistem, English, atau Bahasa Indonesia, dengan tombol Mulai Ulang.

## [1.1.1] - 2026-11-04

### Ditambahkan
- Tentang menampilkan pembuat serta tautan ke GitHub dan source code.
- DMG publik; script pemasang UxPlay ikut di dalam app, jadi wireless bisa disiapkan dari instalasi DMG.

## [1.1.0] - 2026-11-03

Versi publik pertama.

### Ditambahkan
- Mirror iPhone ke jendela biasa yang bisa di-resize lewat USB, tidak pernah fullscreen.
- AirPlay wireless di dalam jendela Cermin, diamankan dengan kode di layar, fail-closed sampai perangkat diizinkan.
- Hotkey Privacy Curtain, screenshot, audio iPhone, rotasi, preset ukuran, dan toolbar di samping jendela.

### Diperbaiki
- iOS 27 tidak lagi meminta kode AirPlay setiap kali tersambung (UxPlay dikunci ke 1.74).

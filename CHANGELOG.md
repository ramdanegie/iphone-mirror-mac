# Changelog

All notable changes to Cermin. Cermin shows the section for your version once after an update (Settings → About → What's New).

## [1.2.0] - 2026-11-04

### Added
- English and Indonesian, with a language picker in Settings → General.
- Update check: Cermin can look for new releases on GitHub (Settings → About), shows the release notes, and downloads the DMG. Daily checks are opt-in, so Cermin stays offline unless you turn them on or press "Check now".
- What's New: after an update, Cermin shows what changed in your version once.

## [1.1.1] - 2026-11-04

### Added
- About shows the author and links to GitHub and the source code.
- Public DMG; the UxPlay installer ships inside the app, so wireless can be set up from a DMG install.

## [1.1.0] - 2026-11-03

First public version.

### Added
- Mirror an iPhone into a regular, resizable window over USB, never fullscreen.
- Wireless AirPlay inside the Cermin window, secured with an on-screen code, fail-closed until you allow the device.
- Privacy Curtain hotkey, screenshots, iPhone audio, rotation, size presets, and a toolbar beside the window.

### Fixed
- iOS 27 no longer asks for the AirPlay code on every connect (UxPlay pinned to 1.74).
